# 🚀 Torresmo Tech | Landing Page

Landing Page desenvolvida para o projeto **Torresmo Tech**, criada para divulgar serviços de consultoria em tecnologia, montagem e manutenção de computadores, além de integrar automaticamente conteúdos do YouTube e Twitch.

O projeto foi desenvolvido utilizando **HTML, CSS e JavaScript**, com integração a APIs externas e banco de dados em nuvem através do **Supabase**.

---

## ✨ Funcionalidades

- 🎥 Exibição automática do último vídeo publicado no YouTube
- 🔴 Exibição da live da Twitch diretamente na página
- 📋 Formulário para solicitação de consultoria
- 📍 Preenchimento automático do endereço utilizando ViaCEP
- ☁️ Armazenamento das solicitações no Supabase
- 📱 Layout responsivo para desktop e dispositivos móveis
- ⚡ Navegação fluida entre as seções da página

---

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de aplicar conhecimentos em desenvolvimento web moderno, integração com APIs e banco de dados, criando uma landing page funcional para o canal **Torresmo Tech**.

Além de divulgar os serviços prestados, o site permite que visitantes acompanhem o conteúdo publicado no YouTube, assistam às transmissões ao vivo da Twitch e solicitem consultorias diretamente pela plataforma.
